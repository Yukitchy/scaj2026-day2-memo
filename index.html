02

来場者の声

来場者が実際に口にした言葉です。左が言葉、下がそこから読めること。

名前とコンセプト

刺さったネーミング最高ですね。香りがいいですね。甘やかしの「ご自身を甘やかしてね」というコンセプトを聞いたあとの感想です。覚醒を飲んだ人が「うまい」と言っていた、と聞いて寄ってくれた方でした。
刺さったじゃあ覚醒をください。眠いので。名前を見て選んだ方です。「朝いつも早いんで、会社に持っていこうかな」と、朝向きと聞いて使う場面を思い浮かべた方もいました。
刺さった何がイレギュラーですか？店名を聞かれた場面です。「その質問を待ってました」から名前の話に入ると、会話が続いていました。別の方には「突飛な豆ではありません」と先に言い切り、そのあとアッパレとドリップバッグのセットを買ってもらえています。
引っかかりシングルには名前はあまり付けないものなんですか？名前が付いていると、ブレンドだと思われやすいです。「実は全部シングルオリジンです」と一言添えた場面がありました。

味

刺さった私も味の違いなんて分からないと思ったけど、比較対象があると分かりやすい。深煎り1種と浅煎り2種を並べて飲んだ来場者の感想です。アッパレは「個性的ですね」とのこと。並べて飲んでもらうと違いが伝わります。
刺さっためちゃめちゃ美味しいですねアッパレと、深煎りの覚醒を続けて飲んだ方です。アッパレは「インドネシアでこんなのあるんだ」と驚かれることが多い、と話していました。
引っかかりG2と言うと下がるのかなって驚くんですよ。ワルツがG2だと聞いたときの反応です。「全然そんなことないです」と答えていました。数字が大きいほどグレードが下がる、という説明だけだと、品質が低いと受け取られます。
要望冷めても美味しいですけど、やっぱり温かいといいですね夕方の試飲での一言です。温かいものを出すと反応が良く、このときは小さいコップが残り少なくなっていました。

買い方・資料

要望卸のお値段の表はありますか？15時台に聞かれた場面です。「デイリープランとプレミアムプランがあって、定番豆の06番がプレミアムで1キロあたり8100円くらい」と答え、名刺を交換して「お送りしてみます」と返ってきました。
要望カフェラテに合う浅煎りを探していて。深煎りが好きなんですが。チョコレート感のある甘やかしを勧め、最後の1つを買ってもらいました。会場では挽き売りができません。「オンラインなら挽いてお出しできます」と案内していました。
引っかかりインスタをフォローしている場合はどうなるんですか？ドリップバッグのプレゼントは？フォロー済みの来場者への特典が決まっていませんでした。この場面は「そのままお豆の購入でもいいですし」と返しています。
引っかかりオンラインで買えるか外国の来場者がブースのTシャツについて聞いた場面です。オンラインに商品がなく買えず、連絡先も聞けませんでした。「メアドかインスタをもらっていたら、新規会員登録で出せたかも」とスタッフ同士で話しています。

ゆみパンさんが夜に共有した、答えに困った質問

手伝ってくれたゆみパンさんが、閉場後にグループへ書いてくれた5つです。コーヒーに詳しくない立場で、実際に聞かれて詰まったものです。録音に答えが残っているものは、つよぽんが実際に言った言葉を添えました。

録音には答えが出てきません。つよぽんが一言で言える答えを、スタッフ全員に共有してください。
「名前がついているものは、ブレンドなんですよね？」
録音でも「みんなブレンドだと思う人が多い」と話されていました。 シングルオリジンですが、ブレンドのように名前を付けて売っています。 「シングルには名前をあまり付けないのでは」と聞かれたときは「それだけだと分からないので、分かるようにしたい」と答えていました。1日目から続く誤解なので、最初の一言にしておくと楽です。
「これはウォッシュですか？ プロセスは何ですか？」

「マンデリンですか？」
マンデリンを聞かれたときの答えは、録音ではこうでした。 こっちはマンデリン。G1グレードのウェットハルです。 どの番号がマンデリンかを、番号と一緒に覚えておくと答えが早くなります。
「インドネシアの豆で、どうやってこの味を出しているんですか？」
インドネシア中心の品揃えについて、つよぽんは次のように話していました。 気がついたら偏っていました。美味しいから。 焙煎でどう味を作っているかの答えは録音になく、つよぽんに決めてもらう項目です。

この5つのうち「湿度」と「どうやって味を出すか」は、答えが録音にありません。つよぽんから一言ずつもらって、スタッフ向けの答えメモに足すのが次の一手です。

1日目からの変化

1日目のふりかえりで決めた「2日目に直すこと3つ」が、実際にどうなったかです。

  1. 試飲のあとに焙煎の話をする　→　効きました試飲のあと、「マンデリンは深めに焙煎した方が美味しい、今回は焙煎を少し奥に攻めています」と話す場面がありました。覚醒の100gも売れています。閉場後には「覚醒もアウトレットと言わずに売って全く問題なかったかも」「1500円で良かった。1000円で売る必要なかった。1万円くらい損してる」と話していました。理由づけがなくても、飲んでもらえば売れます。
  2. リーフレットを渡す　→　半分ですカードで渡したと分かるのは7件で、すべて正午前（9時25分〜11時24分）です。1日目は午前0枚だったので、朝から渡せたのは変化です。ただ午後は録音に渡す場面がなく、閉場後には「渡している量が全然少ない。200部配りきらなきゃいけなかった」と話しています。価格表は朝に印刷し忘れに気づいてローソンで刷り、15時台に「卸のお値段の表」を求められたときは「ありますあります」と答えられました。
  3. 買い方まで言い切る　→　効きました「オンラインでも豆は買えます」「ウェブか公式LINE、インスタからECサイトで」と、お店がない話のあとに続けて言えていました。抜けていたのはTシャツで、買いたい人がいたのにオンラインに商品がありませんでした。

次は、1日目の「全員で」7項目です。

  1. 試飲を切らさない　→　まだです16時台に小さいコップが残り少なくなり、大きいカップで出していました。16時34分の時点で出ていたのはワルツ・誠実・アッパレで、覚醒は出ていません。係を決めたかどうかは録音からは分かりません。
  2. 値札と特典の言い方　→　特典は揃いました「インスタか公式LINEをフォローしてドリップバッグ1個」と、12件のカードで同じ言い方でした。値段は、朝の準備でストアーズの古いリンクに1280円と出て、飛んだ先は1500円だと気づいていました。直ったかは録音からは分かりません。
  3. 登録はインスタのQRを先に見せる　→　効きました朝10時過ぎに「インスタは登録が軽い。公式LINEは面倒でブロックされやすい。ストアーズの会員登録は誰も一人もやっていない」と確認し、以降はインスタを先に出していました。フォローまで進んだ会話はカードで7件。スタッフ自身は「インスタ+100、公式LINE+10くらい」と話しています。
  4. 「卸やってます」をブースに書く　→　録音からは分かりません掲示の話は録音に出てきません。声がけでは「卸もやってるので、もしよかったらお話を」と言っている場面があります。
  5. 会計で止まらない準備　→　大きな詰まりは出ていませんカード決済は差し込みと暗証番号で通り、現金の領収書にも対応できていました。非接触のエラーとお釣りの準備は、録音からは分かりません。
  6. 在庫の置き場所を決める　→　録音からは分かりません置き場所の話は出てきません。かわりに、閉場後に「覚醒をもっと持ってこれた」「200gの需要は無かった」という在庫の反省が出ています。朝には、覚醒のドリップバッグを単品で欲しい人がいたが単品はない、という話もありました。
  7. 英語の一言メモ　→　録音からは分かりませんメモを使った場面は出てきません。外国の来場者は2日目もいて、覚醒を「うまい」と言った方、Tシャツを買えるか聞いた方がいました。
